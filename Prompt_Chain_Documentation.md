# Prompt Chain Documentation

This document explains the step-by-step prompt chaining process used to generate a complete YouTube video.

---

## Prompt 1: Niche Ideation
**Prompt Used:**
Act as a YouTube content strategist.  
Suggest 5 trending video ideas in the niche "AI tools for students".  
Target audience: college students.

**Output:**
1. AI tools that help students study faster  
2. Best free AI tools for assignments  
3. How AI can improve exam preparation  
4. AI tools every engineering student should know  
5. Using AI to manage time and productivity
