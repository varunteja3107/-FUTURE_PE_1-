# Final Video Creation Using AI Tools

## Tool Used
Pictory / InVideo

## Steps
1. Open Pictory or InVideo
2. Paste the full script from Video_Script.md
3. Select automatic scene generation
4. Add AI voiceover
5. Enable subtitles
6. Add background music
7. Export video in MP4 format

## Video Length
Approx. 6–8 minutes

## Output
Final video ready for YouTube upload
