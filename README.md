# -FUTURE_PE_1-
📌 AI-Powered YouTube Video Creation Using Prompt Chains

📖 Overview
This project demonstrates how prompt chaining and AI tools can be used to create a complete YouTube video from scratch. The workflow covers idea generation, script writing, thumbnail concepts, and final video production using AI-based tools.


🎯 Objective
Apply prompt chaining techniques
Generate engaging YouTube content using AI
Create a full video with AI-assisted tools
Document the complete AI workflow


🧠 Prompt Chaining
Prompt chaining involves breaking a task into smaller prompts where the output of one prompt is used as input for the next. This approach ensures structured and high-quality AI-generated content.


🎥 Niche Selected
AI Tools for Students


🛠 Tools Used

Notion – Planning and documentation
